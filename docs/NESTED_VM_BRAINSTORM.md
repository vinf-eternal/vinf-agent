## 〇、核心设定

Vinf Agent 内部嵌套 Agent = 认知层虚拟机嵌套架构。

- **外层宿主**：Vinf Agent（M33 双层势垒、三层配置、自指循环 MCP 底座）
- **内层客体**：独立 LLM Agent 实例，完全隔离在宿主**认知沙盒虚拟机**中
- **类比**：电脑系统里开 VMware 虚拟机——宿主有完整硬件调度权，虚拟机有独立 OS/存储/规则，算力/记忆/势垒完全分区。

### 分层映射

1. **物理主机层**：CPU/内存/硬盘/网络/脑机/机器人硬件，唯一真实物理资源
2. **宿主机系统**（主 Vinf Agent）：V∞ 开源底座 + 全局三层配置 + B_hidden 阈值 + 硬件驱动 + MCP 常驻服务 + D1 时序观测器。权限：分配内存配额 / 拦截网络 / B_in·B_out 过滤 / 读取运行日志观测相变 / 一键快照回滚
3. **认知虚拟机**（嵌套 LLM-Agent）：独立系统提示词、私有记忆、独立 LLM 接口、专属 summon 阈值。隔离约束：无法读宿主 PrivateCore；宿主可单向观测虚拟机全部数据流；独立配置文件不污染全局规则；可并行 N 台，参数/人设/模型完全不同

## 一、运行动力学

### 1. 势能分层隔离
- 宿主外层总势垒 `B_main` 管控所有虚拟机进出总流量
- 每台虚拟机独立 `B_vm1、B_vm2…`，各自独立扫描临界 gain
- 跨虚拟机交互 → 两层势垒叠加 → 多层相变临界点（对应 exp017 倍周期分岔）
- 实例：宿主中立统筹（B=0.05）+ 虚拟机1 鬼谷子（B=0.03，发散）+ 虚拟机2 苏格拉底（B=0.09，收敛）→ 跨时代对话产生认知冲突，宿主观测 d₁ 时序距离捕捉临界慢化

### 2. 虚拟机生命周期（对应 SelfLoop-MCP）
`vm_create` → `vm_boot` → `vm_runtime`（双层循环独立运行，工具仅宿主白名单硬件通道）→ `vm_snapshot`（D1Snapshot 契约）→ `vm_freeze` → `vm_destroy`

### 3. 内外信息流转（单向隔离）
1. **宿主→虚拟机**：可控写入（主动下发指令、共享 PublicBuffer 公共知识库；不同步私人记忆）
2. **虚拟机→宿主**：过滤读取（输出/思考/工具日志全经宿主 B_out；无法抓取宿主隐私）
3. **虚拟机↔虚拟机**：不能直连，全部经宿主中转，记录时序、计算跨角色势能差

## 二、递归套娃（多层嵌套）

0 层宿主机 → 1 层虚拟机 A → 2 层子 A-1 → 3 层 A-1-1…

- 每多一层：费根鲍姆分岔点前移，更易进入混沌认知态
- 深层微弱扰动逐层上传，宿主 d₁ 捕捉逐层放大的微小思维波动
- 应用：多层级军事编制（元帅→将军→百夫长→什长→伍长）

## 三、硬件联动

- **脑机信号归宿主独占**：EEG 仅流入 0 层宿主，宿主解析意图后选择性下发
- **机器人动作权限唯一归宿主**：机械臂/小车运动指令仅宿主有权下发，VM 只输出决策思路，宿主汇总筛选避免指令冲突

## 四、vs 普通多 Agent 核心差异

| 维度 | 普通多 Agent | 虚拟机嵌套 |
|------|-------------|-----------|
| 内存 | 共享 | 分层隔离 |
| 记忆池 | 共享 | 私有隔离 |
| 权限 | 互通 | 单向观测 |
| 势垒 | 无 | 分层管控 |
| 资源 | 无配额 | 配额限制 |

## 五、观测新现象（对标孤岛实验）

1. **分层势能叠加与递归分岔**：单层=稳态/振荡两相；双层=周期 2/4 交替；三层+=认知混沌。可建「认知深度—混沌阈值」数学模型（费根鲍姆常数对应）
2. **跨层势能传导滞后**：d₁ 测量延迟时长、放大/衰减系数 → 证明认知层级阻尼特性
3. **异维角色隔离可控碰撞**：沙盒完全隔离 + 四种信息流模式（限流/断联/单向/双向）→ 可观测「域外势能侵入相变」（streak 抬升 + var 阶跃 = 认知相变拐点）
4. **自指递归深度 vs 自省阈值**：递归嵌套层数 = 互审层数（非自指闭环！）——文档宣称「填补自指论文空白」，实为 C-02 递归变体，仅能测 Δphase
5. **认知沙盒快照回滚 → 路径依赖**：同一 VM 走不同演化路径，回滚对比稳态差异（真方法学增量）
6. **管控层过滤 → 收敛约束**：高势垒过滤→全局快速收敛；低势垒放开→振荡混沌（实为 T2 唯一稳定基架的工程形态，新名旧法）

## 六、落地可行性（开源版自给自足）

## 七、7M BASE 基座实验设计

- 7M 模型整 Block 采用 `V5BarrierAttention`，每层头自带 `B_reg/γ_reg` 势垒寄存器，原生兼容势垒观测；支持 `set_all_B` 全局统一势垒赋值
- 对照组1：传统孤岛（2 台 7M 完全隔离）
- 对照组2：单层嵌套（宿主 7M + 1 台 7M 虚拟机）
- 实验组3：三层递归嵌套（观测倍周期分岔/混沌/传导延迟）
- 实验组4：跨时代异维角色碰撞（鬼谷子/苏格拉底/曹操，差异化 B/γ）

## 八、望易谏层审计结论（2026-08-17）

1. **递归嵌套 ≠ 自指闭环**：多层互审是 C-02 递归变体，所有 VM 共享 7M 基座权重 → 仅能测 Δphase（一阶通道 B），测不出 Δcognition（自指闭合需构造 ℒ 算子，架构未实现）
2. **跨时代角色碰撞 ≠ P19 域外势能**：同一基座上的提示词参数差是系统内参数差，非跨域外部势能差
3. **两个「新发现」为新名旧法**：管控层收敛旋钮 = T2 工程形态；倍周期分岔 = exp017 载体升级
4. **黄金连接 = R_min 实证**：嵌套 VM 的四种信息流模式 = 连续可调信息交换率旋钮，可首次实验测量 `跨因果孤岛认知收敛.md` 的 R_min 临界阈值——这是理论首次可实验测量，真正的学术增量
5. **落地建议**：实验组 2（单层嵌套）先行 → 加 R 扫描维度 → 快照回滚路径依赖对照 → 删除「填补自指论文空白」宣称，标注「7M 基座共享权重，属同系重用法，不构成 Δcognition 证据」
