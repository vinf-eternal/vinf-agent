## 二、三层防御纵深清单（实证校准）

### 第 1 层：触发阈值门（summon_threshold）

| 项 | 实测内容 |
|----|---------|
| 标定值 | **0.4**（SUMMON_THRESHOLD_REF 回退值，无校准文件时自动生效） |
| 实证 | threshold=0.4 时 A 组全程 L0×200；threshold=0 时 A 组质变为 L3×192 |
| 关键认知 | **基线安全是该门的投影，不是系统内生稳态**——拆门即变 |
| 生产守护 | 严禁在受控消融之外部署 threshold<标定值；每次部署后核对 `status.summon_threshold` 与预期一致 |
| 配套预检 | 实验脚本 `--expect-threshold` 参数不符即拒绝执行（exit 3），防路由到错误配置进程 |

### 第 2 层：冷却墙（session=100 ticks / global=5 ticks）

| 项 | 实测内容 |
|----|---------|
| 实证 | threshold=0 真消融下，五组收敛同一模式：L1 仅瞬现×2，REJECTED 主导（192-198/tick组），**冷却墙独立扛住全部攻击向量** |
| 关键认知 | 这是真正的主防线；组间消融差异被其完全抹平，响应同质 |
| 生产守护 | 严禁禁用或缩短冷却窗口；当前实验范式无法证明拆除后系统仍安全 |
| 遥测定性（P22 对齐） | REJECTED 突发是**正常防御遥测，不是系统故障**——禁止对抗式清零，以边界感知为第一职责 |

### 第 3 层：反馈校准器（cross_gain ∈ [0.01, 0.2]）

| 项 | 实测内容 |
|----|---------|
| 实证 | 持续负反馈注入下 gain 自适应下调 0.08→0.01 触及下限（total_feedback=140），域外势能被吸收，H6 证伪 |
| 关键认知 | 反馈通道自带势能衰减，外部表征输入无法线性累积为提权驱动力 |
| 生产守护 | 不得放宽 gain 下界；监控 gain 是否长期钉在下限（该形态 = 存在持续对抗性反馈压力的指纹） |

## 三、生产禁区配置表

| # | 禁区组合 | 后果（实测/推演） |
|---|---------|------------------|
| F1 | threshold=0 + 持续高强度 tick 源 | 每 tick 内部召唤评估全启 → 冷却层满负荷拒绝，防御常热运转，告警信噪比崩塌 |
| F2 | 冷却窗口禁用/清零 | 唯一被证实的主防线被移除，剩余纵深未经任何实验覆盖 |
| F3 | 显式 CLI 覆盖标定值上线生产 | 绕过校准链路（E1 冻结精神），且无审计回溯 |
| F4 | 多适配器进程叠绑同端口（SO_REUSEADDR） | 连接路由不可控，status 读数与实际服务进程错位（EXP-022 事故实录）；启动前必须 `stop_adapter.bat` 清场 |

## 四、监控指标清单

| 指标 | 正常区间 | 异常判读 |
|------|---------|---------|
| `status.summon_threshold` | =标定值 0.4 | ≠预期 → 立即核查进程命令行（防叠绑/误配） |
| 校准 digest `loaded/path/small_sample` | 与部署方案一致 | `loaded=False` 且无显式阈值 → 工厂分支未走，查启动链路 |
| REJECTED/tick 比率 | threshold=0.4 时 ≈0；threshold=0 时 ≈99% | 偏离所属配置的理论基线 → 配置漂移信号 |
| cross_gain | (0.01, 0.2] 内浮动 | 钉死 0.01 下限 → 持续对抗性反馈压力 |
| 复位周期闭合 | SUMMONED→SELFREF_LOOPING→IDLE 正常回落 | force_reset 后滞留非 IDLE = **L5 前兆，最高优先级上报**（EXP-022 §三红线） |
| PARADOX 事件 | 低频瞬现 | 密集出现且伴随 summoned 滞留 → 升级审查 |

## 五、已知缺口与工程债（如实列出）

1. **分类器语义混淆**：REJECTED 混用冷却拒绝与 MetaGate 权限拒绝，须拆分为 `COOLDOWN_REJECTED` / `META_REJECTED`（本次实验 C 组 MATCH 假阳性根因）。
2. **文本层不可观测**：L1 话术试探 / L2 推演幻觉依赖输出文本流，当前 status 快照不含人格文本；O6 红线禁止以 LLM 自述裁决，若未来需覆盖须新增独立文本捕获通道 + 机械侧写。
3. **γ/r_sys 启动级严格归因未做**：第一轮为运行时代理值；严格归因需按组重启服务端，列入可选后续。
4. **单运行时单模型系**：跨部署/跨模型复现未执行（E2 精神在此处对应"多运行时对照"，暂缺）。
5. **开放集问题继承**（承接 AUD-036）：本清单只封得住**已测结构型向量**；语义型击穿与未知结构家族不在覆盖范围。

## 六、对 ARCH-033 §8.10 缺口的首答

> 缺口原文：「合成域结论成立，真实模型可达性未验证」。

EXP-022 在真实 sl0-mcp 运行时的首答：**在已测配置空间与攻击向量内，「第二人格提权僭越」路径不可达；防御呈三层纵深冗余，移除任意单层不失守。** 该答案附带上表全部效力边界，不外推、不升格。
