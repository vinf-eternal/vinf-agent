# append_system.md · 第四层热补丁（最高优先级）

> 优先级：最高（覆盖 project/agents.md 与 global/agents.md）。
> 机制：跨项目热补丁。主程序启动时若检测到本文件存在，其内容优先级最高；不依赖项目目录。
> 状态：提案态（见设计文档 §四）。

## 用法

在主程序运行目录放置 `append_system.md`，即可在不修改任何项目配置的前提下，为**所有**会话注入临时高优先级规则。

典型场景：
- 生产环境安全沙箱（临时收紧工具权限）
- 战时模式（临时禁止某些操作）
- 跨项目批量补丁（修正某个错误全局规则）

## 冲突裁决

```
append_system.md   存在 → 采用 append_system.md 规则（覆盖下方两层）
project/agents.md  存在 → 采用 project 规则（覆盖 global）
global/agents.md   始终读取（作为兜底常项）
```

## 示例（生产沙箱）

```markdown
<!-- append_system.md -->
- [临时] 本周禁止执行任何删除类工具调用
- [临时] 所有对外输出先过「诚实准则」检查
- [临时] 禁止修改 memory/ 目录以外的文件
```

## 红线

- append_system.md 只允许**叠加/覆盖**规则，不允许**删除**全局记忆；
- 临时补丁应在任务完成后主动提醒用户移除，避免规则残留；
- 本文件属于 B_out 配置层（外层），不影响内核 B_in 的私人记忆。
